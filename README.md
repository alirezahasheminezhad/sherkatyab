# شرکت‌یاب (sherkatyab)

جستجوی شرکت‌های ایران از روی کالا یا حوزه فعالیت (مثلاً «ذرت») با داده‌های [رسمیو](https://rasmio.com) — رتبه‌بندی‌شده، ذخیره‌شده در شاخه `db`، با خروجی اکسل/CSV.

**سایت:** `index.html` روی GitHub Pages (شاخه `main`) — تک‌صفحه‌ای، فارسی و RTL، بدون هیچ وابستگی خارجی (فونت وزیرمتن و کتابخانه SheetJS داخل مخزن میزبانی می‌شوند).

## امکانات صفحه
- قفل ورود سمت مرورگر (هش SHA-256 رمز در صفحه؛ همان رمز قبلی کار می‌کند).
- جستجوی تازه با `workflow_dispatch` گیت‌هاب + نمایش زنده وضعیت اجرا (صف/در حال اجرا/پایان)، زمان‌سنج، لینک لاگ و دکمه توقف.
- پایگاه‌داده جستجوهای ذخیره‌شده به‌صورت چیپ‌های قابل کلیک با تازگی/قدمت (TTL = ۷ روز)؛ جستجوی تکراری بدون توکن و بدون اجرای دوباره باز می‌شود.
- جدول قابل مرتب‌سازی (رتبه، نام، سرمایه، تأسیس، مجوز) + فیلتر متنی + فیلترهای آماری کلیک‌پذیر (تأییدشده / پروفایل کامل / دارای مجوز)؛ در موبایل به‌جای جدول، کارت نمایش داده می‌شود.
- کشوی پروفایل کامل: اطلاعات ثبتی، نشانی‌ها و کد پستی (با دکمه کپی)، موضوع فعالیت، هیئت مدیره، بازرسان، دارندگان حق امضا، سهام‌داران، مجوزها، برندها، تغییرات سرمایه، قراردادها، صورت‌های مالی، آگهی‌های اخیر + لینک رسمیو.
- خروجی اکسل (RTL، با عرض ستون) و CSV (با BOM برای فارسی) از همان نتایج فیلترشده/مرتب‌شده.
- پوسته روشن/تاریک، لینک عمیق (`#keyword`)، اعلان‌ها، دسترس‌پذیری (focus trap کشو، aria-live، صفحه‌کلید).

- **مرتبط‌بودن:** هر نتیجه با کلیدواژه و مترادف‌هایش (`synonyms.json`) سنجیده می‌شود (مرتبط / احتمالی / بی‌نشانه) و دلیل مطابقت زیر نام شرکت نوشته می‌شود؛ تیک «فقط نتایج مرتبط» بقیه را پنهان می‌کند. واژه‌های درجه (مثل «قلم») فقط در جستجوی رسمیو حذف می‌شوند.
- **استعلام‌شده:** دکمه «استعلام شد» هر شرکت را از لیست به دسته «استعلام‌شده» می‌برد (قابل بازگردانی؛ در مرورگر ذخیره می‌ماند).

## اجرای جستجوی تازه
۱. در صفحه، بخش «اتصال به گیت‌هاب» را باز کنید.
۲. توکن Fine-grained بسازید: <https://github.com/settings/personal-access-tokens/new>
   - Repository access: فقط `alirezahasheminezhad/sherkatyab`
   - Permissions: **Actions → Read and write**
۳. توکن را وارد کنید (فقط در localStorage همین مرورگر می‌ماند) و جستجو کنید.
گستره جستجو (۱ تا ۱۰ صفحهٔ ۶۰تایی) هنگام ارسال انتخاب می‌شود.

## چگونه کار می‌کند
- `.github/workflows/company-search.yml` → `company_search.py` → `db/companies.json` و `db/searches.json` (یک کامیت روی شاخه `db`).
- `rasmio-mcp` کل صفحه پروفایل را در **یک درخواست** می‌خواند؛ بنابراین همه بخش‌ها (people/ownership/licenses/finance/ads) بدون هزینه اضافه ذخیره می‌شوند.
- رسمیو به هر IP در هر ~۴ روز حدود ۵ پروفایل ناشناس می‌دهد؛ کشو با «جستجوی تازه» به‌تدریج تکمیل می‌شود. شماره تلفن در رسمیو وجود ندارد.
- رتبه‌بندی: ترتیب سرمایه رسمیو + تأیید شرکت + تعداد مجوز + داشتن پروفایل.
- نرمال‌سازی کلیدواژه در صفحه و پایتون یکسان است: نیم‌فاصله→فاصله، ي/ك عربی→فارسی، ارقام فارسی/عربی→ASCII.

## امنیت
قفل صفحه فقط سمت کلاینت است (هش در صفحه) و مخزن/شاخه `db` عمومی می‌مانند؛ برای محرمانگی واقعی مخزن را private کنید. توکن گیت‌هاب هرگز به سروری جز API گیت‌هاب ارسال نمی‌شود.

## توسعه
- تست بک‌اند: `python test_company.py`
- سایت کاملاً ایستا است؛ هر سرور استاتیکی (مثلاً `python -m http.server`) کافی است.
